# 🛒 Project: E-Commerce Sales Data Analysis

## 📌 Project Overview

This project focuses on analyzing an **E-Commerce dataset using Microsoft Excel**.

The project covers the complete data analysis workflow, starting from raw data and data cleaning through analysis, visualization, and reporting.

The main objective is to clean the dataset, analyze sales-related information, identify useful patterns, and present the findings through charts and dashboards.

---

## 🎯 Project Objectives

* Import and organize raw E-Commerce data
* Clean and validate the dataset
* Identify and remove duplicate records
* Handle missing and inconsistent values
* Correct formatting issues
* Apply Excel formulas and functions
* Combine tables using XLOOKUP/VLOOKUP
* Create Pivot Tables for data summarization
* Calculate descriptive statistics
* Create charts and visualizations
* Build an interactive dashboard
* Generate meaningful business insights

---
